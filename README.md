# Simbiosis7

### AI Engineering Platform

**Code · Data · AI · Agents · Cloud · Knowledge · Automation**

Simbiosis7 is an AI-native engineering workspace designed to bring software projects, databases, AI agents, knowledge, infrastructure and automation together in one environment.

</div>

---

## Vision

Modern software systems are distributed across source code, databases, cloud infrastructure, APIs, documentation, logs and multiple development tools.

Simbiosis7 is being built around a simple idea:

> **Engineering systems should work together, not as isolated tools.**

A project can connect its code, data, infrastructure and knowledge to AI agents that can inspect, reason about and operate the project through controlled tools.

## Core Platform

- **Workspace** — organize engineering work in a single environment.
- **Projects** — keep code, data, APIs, environments and infrastructure connected.
- **Data** — work with SQL and NoSQL databases through the integrated database engine.
- **AI** — connect LLM providers and project context.
- **Agents** — planning, execution, verification, memory and tool-based workflows.
- **Knowledge** — code, documentation, schemas, APIs and project knowledge for RAG.
- **MCP** — connect external AI clients and tools through Model Context Protocol.
- **Cloud** — integrate cloud, containers and infrastructure workflows.
- **Automation** — create controlled engineering workflows and scheduled tasks.
- **Observability** — bring logs, metrics, traces and operational context into the project.

## AI Engineering

Simbiosis7 is intended to move beyond a chat interface.

An agent can eventually combine:

```text
Project Context
      ↓
Planner
      ↓
Tools
 ├── Database
 ├── Git
 ├── Files
 ├── Docker
 ├── Cloud
 └── MCP
      ↓
Execution
      ↓
Observation
      ↓
Verification
      ↓
Result
```

Actions that can modify production systems should be designed around explicit permissions, approvals and auditability.

## Database Foundation

Simbiosis7 currently uses the database capabilities inherited from the DBX project as an important foundation.

The database layer provides the foundation for:

- SQL editing
- database connections
- schema exploration
- query execution
- database administration
- multiple SQL and NoSQL systems
- MCP-based database access

The long-term goal is to make database capabilities one part of a broader engineering platform rather than the entire product.

## Status

Simbiosis7 is under active transformation from the original database-client codebase into an AI engineering platform.

The current development direction is:

```text
Phase 1   Workspace + Project
Phase 2   Database integration
Phase 3   AI
Phase 4   Agent Runtime
Phase 5   Knowledge / RAG
Phase 6   GitHub / MCP / Cloud
Phase 7   Automation / Observability
```
