# Simbiosis7

### AI 工程平台

**代码 · 数据 · AI · 智能体 · 云 · 知识 · 自动化**

Simbiosis7 是一个统一的软件工程工作空间，将项目、数据、AI、基础设施、知识和自动化连接在一起。

</div>

---

## 核心理念

现代软件项目同时依赖源代码、数据库、API、云基础设施、文档、日志和 AI 工具。

Simbiosis7 将这些能力组织到同一个 Project 中，让工程环境真正互联。

## 平台能力

- Workspace — 工程工作区
- Projects — 项目管理
- Code — 代码与仓库
- Data — SQL 与 NoSQL 数据
- AI — LLM 与项目上下文
- Agents — 智能体与工具执行
- Knowledge — 文档与 RAG
- MCP — 模型与工具连接
- Cloud — 云与容器
- Automation — 工程自动化
- Observability — 日志、指标与运行状态
