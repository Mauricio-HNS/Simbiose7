# Simbiosis7 Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use GitHub's private vulnerability reporting for this repository when available. If that is not available, open a minimal issue requesting a private security contact without including exploit details, credentials, tokens, connection strings, database dumps, or screenshots containing secrets.

## What to Include

Helpful reports include:

- Simbiosis7 version or commit
- Operating system and installation method
- Affected component
- Safe reproduction steps
- Impact assessment and known workaround

## Security Scope

Security-sensitive areas include:

- Connection storage and encryption
- Database credentials
- SSH tunnels and proxies
- AI provider credentials
- MCP and CLI access
- Docker/web authentication
- Plugin permissions and package verification
- File-system and tool execution boundaries

Please only test systems you own or have explicit permission to assess.
